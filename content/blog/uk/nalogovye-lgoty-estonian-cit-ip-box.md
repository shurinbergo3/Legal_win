# Податкові пільги для бізнесу в Польщі 2026: Estoński CIT, 9% CIT і IP Box

Якщо коротко: у Польщі для бізнесу зі структурою Sp. z o.o. у 2026 році діють три серйозні податкові режими, які при правильній комбінації знижують ефективну ставку оподаткування з базових 19% до 5% (IP Box) або до 0% до розподілу прибутку (Estoński CIT). Ключова помилка більшості іноземних підприємців — обирати режим без аудиту діяльності. Estoński CIT не підходить для бізнесу, який роздає дивіденди щомісяця. IP Box — лише для компаній із реальною інтелектуальною власністю. 9% CIT — для всіх, але з лімітом виручки 2 млн €.

У цьому матеріалі — кому підходить кожен режим, як комбінувати їх, які підводні камені в перший рік, і чому довіряти онлайн-калькуляторам — погана ідея.

## Базова ставка CIT у Польщі

З 2026 року в Польщі діють дві основні ставки податку на прибуток юридичних осіб (CIT):

- **19%** — стандартна ставка для всіх Sp. z o.o., spółek akcyjnych, spółek komandytowych зі ставкою CIT.
- **9%** — пільгова для «małych podatników» (малі платники податків).

Малий платник податків у 2026 — це компанія з виручкою до **2 млн € (≈9,2 млн PLN) у попередньому році**. Якщо у вас у 2025 році зробили 9 млн PLN — у 2026 платите 9%. Якщо 9,3 млн — уже 19%.

Крім CIT, акціонери платять 19% податку з дивідендів при їх фактичному отриманні. Виходить «подвійне оподаткування»: компанія платить CIT із прибутку, потім власник платить 19% з того, що дісталося йому особисто.

Усі три пільгові режими нижче — способи обійти це класичне подвійне податкове навантаження.

## Estoński CIT — що це і для кого

Estoński CIT (формально — «ryczałt od dochodów spółek») — це альтернативний режим, при якому CIT **не сплачується до моменту розподілу прибутку**. Можна копити прибуток роками, реінвестувати, розвивати компанію — податок 0%. CIT з’являється лише при виплаті дивідендів.

При виплаті дивідендів ставка залежить від розміру компанії:

| Тип компанії | Ставка Estoński CIT при розподілі |
|---|---|
| Mały podatnik (до 2 млн € виручки) | 10% |
| Великий podatnik | 20% |

Плюс акціонер платить 19% з дивідендів — але у малого podatnika із зарахуванням частини CIT ефективна ставка знижується до **20%** загального навантаження проти ~34% при стандартній схемі. Для великого — до 25%.

**Кому підходить:**
- Бізнес, який росте і реінвестує прибуток (наприклад, IT-стартап, e-commerce масштабується).
- Компанії, чиї акціонери беруть зарплату через umowę o pracę (це не вважається дивідендом).
- Бізнес, який роками накопичує прибуток для великого кроку (викуп udziały, нерухомість, M&A).

**Кому не підходить:**
- Бізнес, який роздає дивіденди щокварталу.
- Компанії з акціонерами-нерезидентами, для яких дивіденди через складні UPO стають невигідні.
- JDG (Estoński CIT працює лише для spółek z osobowością prawną).

Умови входу:

1. Усі акціонери — фізичні особи.
2. Дохід від пасивних джерел (відсотки, роялті, оренда) — не більше 50% загальної виручки.
3. Мінімум 3 працівники на umowie o pracę (або 4 для małego podatnika).
4. Не торгувати udziałами в інших компаніях.
5. Подати deklarację ZAW-RD до кінця першого місяця фінансового року.

Estoński CIT — режим обов’язково на мінімум 4 роки, потім можна залишитися або повернутися до стандартного.

## 9% CIT — найпростіший інструмент

Якщо ваш бізнес не вписується в Estoński CIT (наприклад, потрібно регулярно платити дивіденди), але виручка до 2 млн €, — у вас за замовчуванням ставка 9% CIT замість 19%. Це застосовується автоматично, без подання спеціальних декларацій. Просто правильно заповнити CIT-8.

Умови:

- Статус «małego podatnika» — виручка ≤ 2 млн € у попередньому році.
- Не існуєте в перший рік, якщо виникли в результаті реструктуризації (m.in. przekształcenia, połączenia).
- Доходи від трансакцій із powiązanymi spółkami — окрема перевірка.

Ефективне навантаження для małego podatnika:
- 9% CIT з прибутку;
- 19% з дивідендів при виплаті;
- загальне навантаження ~26% проти ~34% при 19%.

Це менша економія, ніж Estoński CIT, але без складних умов щодо працівників і без «карантину» 4 років.

## IP Box — 5% на доходи від інтелектуальної власності

IP Box (формально «preferencyjne opodatkowanie dochodów z kwalifikowanych praw własności intelektualnej») — це пільга **лише на доходи, отримані від комерціалізації кваліфікованих прав інтелектуальної власності**. Ставка — **5%** замість 19%.

Які права вважаються кваліфікованими:

- патенти;
- авторські права на комп’ютерні програми;
- захищені промислові зразки;
- селекційні досягнення;
- топографії напівпровідників.

Для IT-сектору головне — авторські права на програми. Якщо ваш JDG або Sp. z o.o. розробляє софт під замовлення або ліцензує його клієнтам, дохід від продажу/ліцензування може оподатковуватися за 5%.

Умови:

1. Ви створили або суттєво модифікували kwalifikowane prawo IP.
2. Дохід від комерціалізації цього права — окремий облік.
3. Витрати на R&D, пов’язані з цим правом, — задокументовані.
4. Подача окремого додатка PIT/IP або CIT/IP до річної декларації.

**Підводний камінь**: IP Box не можна застосовувати до зарплати програміста, якщо він не передав авторські права роботодавцю. Якщо ви IT-фрілансер на JDG, який виставляє invoice клієнту з передачею IP — IP Box працює. Якщо на zleceniu у великій компанії, де IP належить роботодавцю — ні.

Ефективне навантаження для IT-розробника на JDG з IP Box:
- 5% PIT з доходу від IP;
- 9,76% NFZ;
- 19,52% ZUS (але в перші роки — preferred rate);
- загальне навантаження ~30% проти ~50% при стандартній 19% ставці.

## Комбінування

Можна (і часто вигідно) комбінувати режими:

**Sp. z o.o. + Estoński CIT + IP Box.** Компанія на Estoński CIT не платить CIT до розподілу, але додаток IP Box може зменшити базу при майбутньому розподілі. Стратегія для IT-стартапу з реінвестиціями.

**JDG + IP Box.** Найчастіший сценарій для IT-фрілансерів у Варшаві та Кракові. Ефективна ставка 5–10%, але із зобов’язанням документувати кожен IP-дохід.

**Sp. z o.o. малий + 9% CIT + IP Box.** Базовий мікс для більшості IT-компаній з виручкою до 2 млн €. CIT 9% на не-IP дохід + 5% CIT на IP-дохід через додаток CIT/IP.

## Де найчастіше помиляються

**1. Занадто ранній перехід на Estoński CIT.** Стартап у перший рік роботи переходить на Estoński, потім розуміє, що потрібно регулярно виводити гроші — і отримує по повній ставці через вихідну декларацію.

**2. IP Box без документації R&D.** Декларується дохід 100 000 PLN від ліцензії, але на запит urzędu skarbowego немає документації, що компанія реально займалася R&D — відмова + донарахування + пеня.

**3. Перевищення порогу 2 млн €.** Дохід у грудні підстрибнув на 200 000 PLN, виручка перевищила 2 млн €, але компанія не перерахувала CIT з початку року — недоплата + штрафи.

**4. Продовження IP Box після зміни типу договору.** Програміст переходить із JDG у роботу за umowie o pracę — IP Box перестає працювати з моменту зміни структури.

**5. Estoński CIT і закордонні акціонери.** Якщо акціонер — нерезидент, обнулення CIT через Estoński не означає обнулення податку в країні резидентства акціонера. У Німеччині або США дохід усе одно може оподатковуватися. Це треба перевірити через UPO.

## Коли потрібен податковий консультант

Самостійно впоратися можна, якщо: один режим, проста структура, JDG без IP, Sp. z o.o. з одним власником.

До консультанта має сенс іти, якщо:

- комбінування режимів;
- IP Box при IT-діяльності;
- перехід з одного режиму на інший;
- структура із закордонними акціонерами;
- виручка близька до порогу 2 млн €;
- попередні відмови або зауваження urzędu.
